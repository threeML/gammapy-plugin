# Installation

You will need to install `threeML`, `astromodels` and of course `gammapy` within one
Python environment.
Thanks to `conda` this is now pretty straight forward.
:::{note}

Workin on a conda and pypi package for gammapy-plugin as well!

:::

## Summary
```bash
conda install -c threeML -c conda-forge threeml astromodels
conda install -c conda-forge "gammapy>=2.0.0"

pip install git+https://github.com/threeML/gammapy-plugin.git


```
